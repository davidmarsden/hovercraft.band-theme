# Content migration

The old Hovercraft site is a quarry, not a template.

## Keep / refresh

Highest priority:

- canonical lyrics and established lyric URLs;
- current recordings and audio URLs;
- release artwork;
- useful band history;
- selected press material;
- externally linked pages worth preserving.

## Curate / archive

Likely candidates:

- old press and reviews;
- flyers and photographs;
- historical announcements;
- superseded biographies;
- legacy release material that remains interesting but is no longer current.

## Replace / retire

Navigation, homepage structure, styling and duplicated or stale promotional copy can be replaced freely.

## Audit states

Each existing public URL will eventually be classified as:

- **keep** — retain URL and substantially retain content;
- **refresh** — retain URL but rewrite/redesign content;
- **move** — new canonical location plus redirect/compatibility route;
- **archive** — preserve as historical material;
- **retire** — remove only where there is no continuing value or meaningful inbound-link risk.

Do not delete legacy content in bulk before this audit is complete.
